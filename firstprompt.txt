You are a senior full-stack architect. Build a complete production-ready social
media platform called VAANJAY — a super-app combining Instagram, WhatsApp,
Facebook, Twitter, WeChat, and Reddit, designed specifically for Tamil Nadu and
Tamil culture. The app must be a cross-platform product: Android app, iOS app,
and a responsive web app — all sharing one backend.

SECTION 1 — TECH STACK (PERFORMANCE-FIRST)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Choose a stack that:
• Uses minimum RAM, CPU, and storage on the user's device
• Offloads processing to the device whenever possible (on-device compression,
on-device video encoding before upload)
• Minimizes server calls using aggressive local caching
Stack:
• Mobile App: React Native (Expo bare workflow) — single codebase for Android + iOS
• Web App: Next.js 14 (App Router) — SSR + SSG for performance
• Backend API: Go (Golang) with Fiber framework — ultra-low memory, high concurrency
• Realtime (DMs, calls signaling, live reactions): Go + WebSocket (gorilla/websocket)
• Video/Audio Calls: WebRTC (via Pion in Go backend, mediasoup optional)
• Database: PostgreSQL (primary) + Redis (caching, sessions, online presence)
• Media Storage: Cloudflare R2 (S3-compatible, cheap, fast CDN)
• On-device media: Use React Native's built-in camera + FFmpeg-kit for
compression before upload
• Push Notifications: Firebase Cloud Messaging (FCM)
• Payments/UPI: Razorpay SDK (supports UPI, UPI QR, PhonePe, GPay, Paytm)
• Authentication: JWT (access + refresh tokens) + OTP via SMS (Twilio or MSG91)
• Admin Panel: Next.js web dashboard (separate route /admin, same codebase)
• Monorepo structure using Turborepo:
/apps/mobile → React Native
/apps/web → Next.js
/apps/admin → Next.js admin panel
/services/api → Go backend
/services/rtc → WebRTC signaling server
/packages/ui → Shared UI components
/packages/types → Shared TypeScript types

SECTION 13 — BUILD ORDER INSTRUCTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Build in this exact order to avoid dependency issues:
Step 1: Generate monorepo scaffold (turbo.json, root package.json)
Step 2: Generate all SQL migration files in /services/api/migrations/
Step 3: Build Go backend — models, repositories, handlers, middleware
Step 4: Build WebSocket server and WebRTC signaling server
Step 5: Build shared TypeScript types in /packages/types/
Step 6: Build shared UI component library in /packages/ui/
Step 7: Build Next.js web app — auth pages first, then main app,
then admin panel
Step 8: Build React Native mobile app — auth screens first,
then tab screens, then all stacks
Step 9: Build i18n locale files — Tamil first, then English,
then other languages
Step 10: Generate docker-compose.yml and .env.example
Step 11: Generate README.md with full setup, run, and deploy
instructions in both Tamil and English
